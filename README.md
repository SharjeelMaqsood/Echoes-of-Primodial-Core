 Echoes of Primodial Core

A 3D game developed in Unity as my Final Year Project.

About the Game

Echoes of Primodial Core** is a 3D survival game developed using Unity and C#.

The project was created as my Final Year Project, with a focus on gameplay programming, game systems, player interaction, and overall game development.

Gameplay


Features

* 3D gameplay
* Player movement and controls
* Gameplay systems and interactions
* Enemy / obstacle systems
* UI and game-state management
* Audio and visual effects
* Multiple gameplay elements and mechanics

Built With

* **Unity**
* **C#**
* **Unity Physics**
* **Unity UI**
* **Particle System**
